# Automated Resume Ranking System

An easy-to-use web application that helps rank candidate resumes based on their relevance to a given job description. This project is designed to assist in faster and more efficient resume shortlisting.

---

## 📌 Project Overview

The Automated Resume Ranking System allows users to:
- Paste a job description
- Upload multiple resumes
- Automatically receive a ranked list of resumes based on relevance

This system is useful for:
- Recruiters
- HR teams
- Students learning about resume screening systems

---

## ✅ Key Features

- Upload multiple resumes at once
- Supports PDF, DOCX, and TXT file formats
- User-friendly web interface
- Automatically ranks resumes based on job description relevance
- Displays results instantly
- Simple and clean UI

---
